# Pika API audit — 2 October 2026

The integration does **not** match the entire current API perfectly. It covers
152 of 160 callable model operations (95%), and some accepted input combinations,
response variants, billing behavior and account APIs remain unsupported.

Ten GPT-6 Luna reviewers examined separate slices: video, image, audio, language
models, catalog completeness, request validation, job lifecycle, uploads, billing,
and security/function exposure. The parent implemented and tested Seedance prompt
reference autocomplete while reviews ran. Six reviewers ran concurrently, with
later reviews taking freed slots.

## Confirmed behavior and input gaps

- **P2 — Required prompts vary by operation, but the UI only declares them per
  model.** HappyHorse 1.0 reference/video-to-video and 1.1 reference-to-video
  require prompt text, although their image-to-video siblings permit omitting it.
  The shared optional-prompt setting lets attached-media requests omit the required
  field. See `src/generation/catalog/video/alibaba.ts:51` and
  `src/generation/to-platform.ts`'s blank-text omission. Resolve prompt requirements
  against the selected operation. Empty text-only requests were also reported by
  reviewers, but the normal composer disables Generate when both words and media
  are absent; those are serializer-validation gaps, not demonstrated UI paths.
- **P2 — Pikaframes permits one image; the API requires at least two.**
  `src/generation/catalog/video/pika.ts:267` only marks the array required and caps
  it at five. The picker and request mapper need an operation-level minimum.
- **P2 — Seed Audio permits incompatible reference and voice choices.**
  `src/generation/catalog/audio/bytedance.ts:182` exposes image and audio references
  together, while its schema describes them as mutually exclusive. A preset voice
  can also be combined with an explicitly selected multilingual variant, which
  supports reference cloning instead. Validate combinations before submitting.
- **P2 — Pika Speech sends a preset alongside a clone recording.**
  `src/generation/catalog/audio/pika.ts:163` always maps its default voice preset
  even with `reference_audio`. The catalog's own comment describes these as
  mutually exclusive modes. Choose the applicable mode and omit the other input.
- **P2 — Audio-source dubbing is unavailable.** Eleven Voice Dubbing's documented
  `source_url` accepts audio or video, but `roles` and bindings expose only video
  (`src/generation/catalog/audio/elevenlabs.ts:193`).
- **P2 — Persisted numeric settings need integer/step validation.**
  `src/generation/catalog/parse-settings.ts:17` checks bounds only. For example,
  Kling accepts a persisted duration of `5.5` even though its API requires an
  integer. Its slider uses whole seconds, so this concerns persisted/custom
  state rather than a normal slider selection.
- **P2 — Dialogue turns lack required nested validation.**
  `src/generation/catalog/audio/elevenlabs.ts:69` can build a turn with an empty
  `voice_id` or more than 3,000 characters. Voice IDs can be cleared in settings,
  and retained audio prompt text can exceed a turn's limit after switching models.

Schema-compatible controls are often deliberate subsets. Omitted masks, structured
Sonilo segments, output plumbing and curated enum lists are feature limitations,
not automatically invalid wire requests. In particular, Seedance's duration rail
omits `auto`; the documented edit workflow requires `duration: "auto"`, so the
full edit workflow still needs that choice and its ratio/task constraints.

## Job lifecycle and billing

- **P2 — Transient status errors end local job tracking.**
  `src/generation/actions.ts:87` catches each status exception and returns an error
  result; `src/generation/poll.ts:90` immediately rejects that watch. The UI marks
  the history row failed even when the upstream job may still run. Retry transient
  failures per job before ending the watch.
- **P2 — An uncertain submit retry can create another paid job.**
  `src/generation/platform.ts:93` creates a new idempotency key per submit call.
  Retain the same key/body while recovering an uncertain response; a deliberate
  new request or retry of a known failed job should use a fresh key.
- **P2 — Admission errors lose actionable metadata.** The server action/UI path
  reduces exceptions to messages, rather than preserving stable `error.code` and
  `Retry-After`. See `src/openhiggsfield/openhiggsfield-app.tsx:200` and
  `src/generation/platform.ts:278`. Balance/cycle-limit failures and rate limits
  need distinct handling.
- **P2 — Multiple-video outputs are not mapped.** The live OpenAPI includes
  `VideosOutput` with a `videos` array. `src/generation/platform.ts:227` handles
  `video`, `images`, `audio` and `transcript` but omits `videos`. The active operation
  producing that variant was not established, so this is a response-contract gap.
- **P2 — Topaz Video Upscale prices are stale.**
  `src/generation/catalog/pricing.json:3994` retains second-based pricing; the live
  catalog uses delivered megapixels and output-frame components. The current
  estimator cannot correctly price those new units. Refresh metadata and support
  the units, or use the platform quote.
- **Account functions are missing:** quote, balance, daily spend, monthly report
  and CSV. `src/generation/platform.ts:92` exposes submit/status/upload/chat only.
  There is no prepaid or postpaid-cycle capacity check before generation.
- **Settled charges are discarded:** status mapping omits both `usage` and
  `billing`, so actual charges cannot be displayed or reconciled. Preserve charges
  only when `billing.state` is `settled`; pending/unavailable states need retries.

## Uploads and broader capability limits

- **P1 — Full request/response logging exposes sensitive generation data.**
  `src/generation/platform.ts:73` and `:85` log full bodies, including prompts,
  input media URLs and upload tickets with temporary signed URLs/headers.
  Replace these with allowlisted metadata such as method, path, status and job ID.
- **P2 — Upload fallback buffers an unbounded body before checking it.**
  `src/app/api/upload/route.ts:12` calls `arrayBuffer()` before ticket creation and
  authentication/size enforcement. Add server-side bounds before or while reading
  the request. Deployment-level request limits were not assessed.
- **Conditional hardening concern — Transcript polling trusts upstream URLs.**
  `src/generation/actions.ts:110` fetches a supplied transcript URL server-side
  without host/scheme checks, a timeout or response-size bound. An SSRF exploit
  would require influence over that upstream URL; that influence was not proven.
- **Documentation ambiguity, not a confirmed rejection:** OpenAPI's binary upload
  MIME list omits video and FLAC while the index documents video uploads. The JSON
  ticket schema does not restrict MIME values enough to settle this. Verify against
  the ticket-flow contract before changing the picker allow-list.
- Local history deletion and upload-shelf eviction do not call remote job/upload
  deletion. This is a retention choice, but remote erasure is unsupported.
- Webhook registration/delivery inspection/signature verification and LLM streaming
  are not exposed. The current synchronous LLM requests use all three documented
  protocols correctly for their text-only scope.
- The Google text model description says multimodal, but all text entries expose
  no attachment roles. GenAI's serializer is text-only. This is misleading capability
  copy, not evidence that the current normal UI drops attachable Gemini images.

## Implemented in this change

Seedance prompt references now show attached images/video/audio when typing `@`.
Prefix filtering is case-insensitive. Arrow keys select; Tab/Enter or a click
inserts the canonical token. Escape closes suggestions and Shift-Tab navigates
normally. IME composition and selected text preserve textarea behavior. Start/end
frames are not mislabeled as positional references. Thumbnail labels match the
selected operation's actual per-role URL-array order and caps across all four
Seedance versions. The menu clears the attachment strip.

Regression checks live in `scripts/check-references.ts`, exposed as
`pnpm check:references`. They verify aliases against actual serialized requests,
per-role indexing, caps, operation selection, caret replacement and email/selection
exclusion. Browser tests used a temporary fixture with no paid submit handler;
the fixture and its test inputs were removed afterward.

## Findings fixed in the follow-up

The sections above preserve the original audit baseline. The following changes now resolve its confirmed findings:

| Area | Resolution |
| --- | --- |
| Catalog coverage | All eight missing operations added; 112 model entries cover all 160 callable operations: 74 video, 34 image, 28 audio, 24 text. All 162 expanded catalog records refreshed; the two schema-less Google image aliases are excluded from callable coverage. |
| Schema validation | The selected operation’s final mapped body is checked in the composer and on the server against 136 imported schemas, including required prompts, nested references, array minima, enums and numeric bounds. Settings are clamped and step-normalized. Creative text is validated rather than truncated. |
| Audio | Seed Audio rejects incompatible references/variants; Pika Speech omits presets for cloning and requires the documented consent attestation; dubbing supports audio and video; dialogue checks required voice IDs and per-turn length. |
| Seedance | Draft creation and finalization, Auto duration, and edit/extend constraints supported. Saved completed drafts can be selected from history. Existing positional reference autocomplete remains aligned with submitted arrays. |
| Job lifecycle | HTTP error codes, status, retry delays and identifiers preserved. Transient polling errors receive bounded retries; exhausted tracking stays running locally with a resume control. Multiple-video outputs are retained. |
| Submission recovery | Original body and idempotency key saved before a paid submit; uncertain responses reuse both. Accepted job IDs remain recoverable until history is durably written. Stale fallback storage cannot resurrect a removed key. Mapping changes retain the unresolved key instead of submitting a different body. |
| Billing/pricing | Topaz’s current usage rates shipped, debounced live public list-price quotes shown, and quote/capacity preflight added for media batches. Quotes exceeding displayed capacity are advisory because organization pricing can differ. Balance, daily spend, monthly reports/CSV, usage, and settled job charges supported. Charges cover all outputs and are not inferred from pending billing. |
| Privacy/uploads | Full platform body logging removed. Relay authenticates before bounded reads and verifies a server-issued HMAC ticket bound to key, URLs, signed headers, MIME, size and expiry. Browser and relay use the same minted ticket. Transcript reads restrict hosts, redirects, timeout and body size. |
| Remote erasure | Explicit viewer and upload-library controls, separate confirmation, and safe repeat handling. Job-deletion 503 means accepted background cleanup; upload-deletion 503 remains retryable. Gallery deletion remains local with Undo. |
| Streaming/webhooks | All three LLM protocol families stream into text tiles. OpenAI/Anthropic use `stream: true`; GenAI uses `:streamGenerateContent?alt=sse`. Standard Webhooks signatures and timestamps verified; receipts stored before ACK and deduplicated. Recent delivery inspection is available in Usage. Registration stays in the Pika dashboard. |

`pnpm sync:catalog` also regenerates the client/server request schema bundle, preventing later snapshot refreshes from leaving validation stale.

Follow-up verification covers every media request schema with 137 mapped bodies, all newly added operations, audio constraints, reference ordering, current pricing, durable recovery, mock runtime errors/retries/outputs, signed relay tampering and expiry, webhook verification/deduplication and three vendor stream parsers. TypeScript and production builds passed. Browser checks verified one-frame rejection/two-frame acceptance, saved draft selection, arrow + Tab completion, live public quotes, streaming previews, the Usage panel, and erasure confirmation without executing remote erasure.

No paid provider generation was executed. Coverage means callable endpoints are represented; optional masks, structured Sonilo segments and other curated controls remain deliberate UI subsets. Provider-specific cross-field behavior beyond published schemas still needs real-provider coverage. MIME ambiguity noted above remains unproven rather than being “fixed” by removing supported video roles.

Webhook receipts require a persistent volume for a single host; multiple instances need shared transactional deduplication. Upload relay replicas require the same configured server secret. Webhook receipts do not replace browser polling or automatically hydrate another browser’s history.
